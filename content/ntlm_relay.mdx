# Explications

Voici un exemple de billet de démonstration pour illustrer le rendu MDX.

Les attaques de type "NTLM Relay" permettent à un attaquant de relayer des authentifications NTLM entre un client et un service.

![image](/image.png)

<br></br>

# Details

Un résumé clair et quelques étapes :

- Comprendre le protocole NTLM
- Capturer une authentification
- Relayer l'authentification vers la cible

# Commande exemple

<CommandGroup>
  <Command tool="ntlmrelayx">
    ```bash
    ntlmrelayx -I eth0 -smb2support
    ```
  </Command>

  <Command tool="krbrelayx">
    ```bash
    krbrelayx -I eth0 -smb2support
    ```

  </Command>

  <Command tool="responder">
    ```bash
    Responder -I eth0 -wb -r 10.0.0.5 | cme smb "$USER" -p "password" -d 'domain.local'
    ```
  </Command>
</CommandGroup>
